# Análise de Dados - E-commerce

Este projeto tem como objetivo realizar uma análise exploratória de dados de um e-commerce, com foco em entender o comportamento de vendas por marca.

## Análises realizadas
- Análise descritiva dos dados
- Identificação de valores nulos
- Top 10 marcas mais vendidas
- Relação entre preço e quantidade vendida

## Visualizações
- Histograma
- Gráfico de dispersão
- Mapa de calor
- Gráfico de barras
- Gráfico de pizza
- Gráfico de densidade
- Regressão

## Tecnologias utilizadas
- Python
- Pandas
- Seaborn
- Matplotlib

- ## Principais Insights

- Algumas marcas concentram maior volume de vendas
- Existe relação entre preço e quantidade vendida
- A distribuição de preços mostra padrões relevantes
